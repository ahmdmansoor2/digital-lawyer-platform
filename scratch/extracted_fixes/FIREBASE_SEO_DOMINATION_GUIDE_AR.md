## 2. خطوات التطبيق الآمن على جهازك (في 3 دقائق)

1. **نسخ الملفات الجديدة إلى مجلد النشر:**
   انسخ صفحات الـ HTML الـ 12 الجديدة وملفي `llms.txt` و `llms-full.txt` إلى مجلد النشر في مشروعك (مثل `public/` أو `dist/`)، وضع `firebase.json` في المجلد الجذري للمشروع.

2. **تشغيل سكريبت الإلحاق والترقية الآمن (`seo_safe_injector.py`):**
   افتح الطرفية (`Terminal` أو `Command Prompt`) داخل مجلد المشروع وشغّل الأمر:
   ```bash
   python seo_safe_injector.py ./public
   ```
   سيقوم السكريبت تلقائياً بـ:
   - الإبقاء على كافة روابط `sitemap.xml` الـ 607 وإضافة الـ 12 رابطاً جديداً فقط (الإجمالي **619 رابطاً**).
   - تحديث `search-index.json` من 935 إلى **947 صفحة** دون حذف أي سجل.
   - حقن صناديق الربط الداخلي العنقودي (`Topic Clusters`) داخل مقالات المدونة الـ 402.
   - ترقية الصفحة الرئيسية `index.html` بالواجهة التفاعلية الجديدة مع **سحب أسماء ملفات Vite JS/CSS الحية تلقائياً من ملفك الأصلي** وحفظ نسخة احتياطية في `index.backup.html`.

3. **النشر إلى Firebase Hosting:**
   ```bash
   firebase deploy --only hosting
   ```
