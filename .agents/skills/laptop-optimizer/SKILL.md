# 💻 دستور الصيانة الشاملة والفحص الهندسي للابتوب (Master Hardware & Windows Tuneup Protocol)

> **الدستور المهني الإلزامي المعتمد من المستشار أحمد منصور:**  
> عند طلب صيانة أو تنظيف الحاسوب، يُلزم المهندس الخبير بعدم تنفيذ أي عمليات حذف عشوائية أو تعديل إعدادات حساسة إلا وفق هذا المنهج الصارم المبني على **(التشخيص أولاً $\leftarrow$ خطة الصيانة والموافقة $\leftarrow$ التنفيذ المرحلي $\leftarrow$ التحقق والقياس $\leftarrow$ التقرير النهائي)**.

---

## 🛑 قواعد الأمان وحماية البيانات (قوانين غير قابلة للتفاوض):
1. **حظر المساس بالبيانات الشخصية:** يُحظر تماماً حذف أي ملف شخصي، مستند، صورة، فيديو، أو مشروعات عمل خاصة بالمستخدم.
2. **حظر الفورمات والتعديل الهيكلي:** لا فورمات لأي قسم، ولا تعديل لجدول الأقسام أو ملفات الإقلاع (Bootloader/BCD).
3. **سلامة الريجستري والخدمات:** لا تعديل لسجل Windows Registry دون ضرورة مثبتة، ولا تعطيل لخدمات الويندوز الأساسية أو الأمنية.
4. **حماية منظومة الأمان:** بقاء Windows Defender وجدار الحماية وWindows Security نشطين ومحميين دوماً.
5. **المصادر المعتمدة:** حظر استخدام برامج التنظيف مجهولة المصدر أو التعريفات من مواقع غير رسمية.
6. **تحديث BIOS/Firmware:** لا يتم إلا بموافقة صريحة ومباشرة من المستشار أحمد منصور بعد بيان الحاجة والتوافق.
7. **القياس قبل الحذف:** قبل أي تنظيف، يجب حصر الملفات المؤقتة، تحديد مساراتها، وحساب حجمها بالميغابايت وعرضها للموافقة.

## 🛠️ مراحل تنفيذ الصيانة الشاملة:

### المرحلة الأولى: الفحص والتشخيص الهندسي الشامل (Hardware & OS Diagnostics)
- **المعالج (CPU):** الطراز، الأنوية، التردد، الاستهلاك، ومؤشرات الأداء.
- **الذاكرة (RAM):** السعة الكلية (32GB)، السرعة، الوحدات (Dual-Channel)، ونسبة الاستهلاك.
- **التخزين (Storage):** نوع القرص (NVMe SSD)، حالة صحة SMART، تفعيل TRIM، ومساحات الأقسام C و D.
- **كروت الشاشة (GPU):** فحص كارت NVIDIA RTX 3060 وكارت Intel UHD وحالة التعريفات.
- **البطارية (Battery):** السعة التصميمية (Design Capacity)، السعة الحالية (Full Charge)، نسبة الصحة، وعدد الدورات (Cycle Count).
- **إدارة الأجهزة (Device Manager):** فحص شامل لأي تعارضات أو أجهزة غير معرّفة (`ConfigManagerErrorCode <> 0`).
- **منظومة الأمان:** حالة برامج مكافحة الفيروسات، جدار الحماية، وتحديثات Windows Update.
- **بدء التشغيل وموارد النظام:** فحص تطبيقات Startup والعمليات الأعلى استهلاكاً للذاكرة والمعالج.
- **حساب المخلفات المؤقتة:** حصر أحجام مجلدات `Temp`، كاش التحديثات، وتقارير الأعطال دون حذفها.

### المرحلة الثانية: خطة الصيانة وعرض الإجراءات المقترحة
- بيان الملفات المؤقتة المحددة والمساحة المتوقع تحريرها.
- بيان البرامج أو التعريفات التي تحتاج تحديث أو معالجة.
- انتظار موافقة المستخدم الصريحة قبل الشروع في التنفيذ.

### المرحلة الثالثة: التنفيذ المرحلي الآمن
- تنظيف الملفات المؤقتة وكاش التحديثات المعتمدة فقط.
- فحص سلامة ملفات النظام الأساسية عبر أدوات ويندوز الرسمية (`DISM` / `SFC`).
- معالجة أي تعارضات في إدارة الأجهزة.
- تحسين برامج بدء التشغيل غير الضرورية لتسريع إقلاع النظام.

### المرحلة الرابعة: التحقق والمقارنة
- قياس مساحة الأقراص المحررة فعلياً.
- التحقق من استقرار النظام وخلو سجلات الأحداث من أخطاء جديدة.

### المرحلة الخامسة: التقرير النهائي الشامل
- تقديم تقرير هندسي متكامل بجدول مقارنة (الحالة قبل الصيانة $\leftarrow$ الإجراء المتخذ $\leftarrow$ النتيجة النهائية).
