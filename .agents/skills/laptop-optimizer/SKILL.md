# 💻 مهارة الفحص الشامل وصيانة اللابتوب (Laptop Tuneup & Optimizer)

هذه المهارة مخصصة لإجراء فحص دوري شامل وعميق للابتوب الأستاذ أحمد منصور (Lenovo Legion 5) وتحسين أدائه وتنظيفه بضغطة زر واحدة.

---

## 🛠️ ما تقوم به المهارة تلقائياً عند طلب فحص اللابتوب:

1. **فحص سلامة العتاد والهاردوير (Hardware Diagnostics):**
   - فحص صحة المعالج Intel Core i7-11800H والأنوية ومعدل الاستهلاك.
   - فحص كروت الشاشة (NVIDIA RTX 3060 Laptop GPU + Intel UHD) والتأكد من استقرار التعريفات.
   - فحص الذاكرة العشوائية (RAM 32GB) ونسبة الاستهلاك والعمليات الأعلى استنزافاً.
   - فحص سلامة بطارية اللابتوب ونسبة الشحن وحالتها التشغيلية.

2. **فحص ومراقبة مساحات الأقراص التخزينية (Disk Space & SMART):**
   - قراءة مساحات قرص النظام `C:` وقرص البيانات `D:`.
   - التأكد من سلامة القرص الصلب فائق السرعة Samsung NVMe SSD.
   - التحقق من عدم وجود ملفات محجوزة غير مستخدمة (مثل `hiberfil.sys` أو كاش التحديثات الميتة).

3. **التنظيف الذكي لمجلد المستخدم (`C:\Users\احمد منصور`):**
   - المسح التلقائي لأي سجلات نشر قديمة (`*.log`).
   - حذف ملفات ومخلفات صفحات الاختبار والمحاولات السابقة (`cf-*`, `deploy-*`, `live-*`, `verify-*`).
   - الحفاظ الصارم على ملفات النظام (`NTUSER.DAT`) وإعدادات بيئة التطوير (`.gitconfig`, `.gemini`, `.vscode`, إلخ).

4. **تنظيف كاش النظام ومخلفات الحزم البرمجية:**
   - تفريغ المجلدات المؤقتة `AppData\Local\Temp` و `C:\Windows\Temp`.
   - تفريغ كاش حزم Node.js (`npm cache clean --force`).
   - إزالة بقايا تنزيلات Windows Update غير المكتملة.

5. **فحص سلامة التعريفات والحماية والأمان:**
   - فحص Device Manager للتأكد من عدم وجود أي علامات تعجب صفراء أو تعريفات تالفة.
   - فحص حالة Kaspersky و Windows Defender للتأكد من نشاط جدران الحماية.
   - التحقق من تحديثات البرامج وحزم النظام عبر `winget`.

---

## ⚡ أمر التنفيذ الفوري للمهارة:

لتطبيق كافة خطوات الفحص والتنظيف والصيانة دفعة واحدة:
```bash
node scripts/maintenance/system-tuneup.cjs
```
