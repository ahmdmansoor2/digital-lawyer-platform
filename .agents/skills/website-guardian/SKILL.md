# 🛡️ مهارة الحارس الذكي ورعاية المنصة (Website Guardian & Auto-Care)

هذه المهارة مخصصة للحفاظ على أمان واستقرار وتشغيل **منصة المحامي الرقمية** (`mohamidigital.online`) على مدار الساعة وبشكل مستقل تماماً في السحابة.

---

## 🏛️ 1. مبادئ الحراسة والأمان المعماري (Architectural Non-Negotiables)

1. **الاستقلالية السحابية الكاملة (Cloud-First 24/7):**
   - كافة مهام النشر والمراقبة (Workflows) تعمل عبر **GitHub Actions السحابية** (`runs-on: ubuntu-latest`) ومربوطة بـ Firebase Hosting و Facebook Graph API و YouTube API دون الحاجة إلى تشغيل الجهاز المحلي.
2. **منع الأخطاء التخريبية (Zero-Downtime Protection):**
   - قبل أي نشر على Firebase: مسح الكاش المحلي `.firebase/hosting.*.cache`.
   - استهداف الموقع المخصص حصراً: `--only hosting:app --project justice-91571`.
3. **حماية الهوية البصرية وجودة الخطوط (Typography 2.0 Integrity):**
   - الحفاظ على محرك التنعيم الصارم `-webkit-font-smoothing: antialiased` و `text-rendering: optimizeLegibility`.
   - الحفاظ على أوزان الخطوط الواضحة (`500/600/800`) والتباين العالي للنصوص البيضاء مع ظلال الحروف الدقيقة (`text-shadow`).

## 🛠️ 3. إجراءات التعافي الذاتي من الطوارئ (Self-Healing Runbooks)

### السيناريو 1: نفاد كوتة الذكاء الاصطناعي (Gemini Quota Exceeded)
- **الإجراء:** السكربتات مزودة بقائمة تعافٍ متدرجة تلقائياً:
  `gemini-3.6-flash` ⬅️ `gemini-3.5-flash` ⬅️ `gemini-3.1-flash-lite` ⬅️ `gemini-3.7-flash`
- التبديل يتم تلقائياً دون توقف المهمة.

### السيناريو 2: تضارب سباق الدفع على Git (Push Race Condition)
- **الإجراء:** كل الـ workflows تسبق أمر الدفع بـ `git pull --rebase origin main` لتفادي الخطأ `128` وضمان تزامن السجل.

### السيناريو 3: كاش المتصفح القديم لدى الزوار (Browser Cache Desync)
- **الإجراء:** فهرس البحث والأصول الحساسة يتم طلبها عبر معرّف الطابع الزمني `?t=Date.now()` لفرض التحديث الفوري.

عند بدء أي جلسة جديدة أو للتحقق من سلامة الموقع، قم بتشغيل:
```bash
node scripts/monitor/health-check.cjs
```
