# مجلد الموسيقى الخلفية

ضع هنا ملفات MP3 أو WAV royalty-free عشان الفيديو يطلع مع موسيقى.

## مصادر موسيقى مجانية (royalty-free)

- **YouTube Audio Library** — https://www.youtube.com/audiolibrary
  (مجاني، بدون قيود تجارية على معظم المقاطع)
- **Pixabay Music** — https://pixabay.com/music/
  (مجاني، بدون attribution مطلوب)
- **Uppbeat** — https://uppbeat.io/
  (مجاني بـ 10 تحميلات/شهر، جودة عالية)
- **Mixkit** — https://mixkit.co/free-stock-music/
  (مجاني بالكامل، بدون تسجيل)

## التوصية

- مدة 1-2 دقيقة كافية (السكريبت 60-90 ثانية + loop)
- الموسيقى الهادئة (lo-fi / chill) مناسبة للمحتوى القانوني
- **ممنوع** استخدام أغاني فيها كلام — بيتعارض مع الـ TTS
- الحجم: أقل من 5 MB

## الاستخدام

بعد ما تنزّل أي ملف MP3 هنا، النظام هيختار واحد عشوائياً تلقائياً.

أو حدد ملف معين في `.env`:
```
BACKGROUND_MUSIC_PATH=D:\قانوني 7\scripts\tiktok-publisher\assets\music\your-track.mp3
```
