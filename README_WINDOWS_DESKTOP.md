# دليل تشغيل وتصدير البرنامج كبرنامج سطح مكتب لنظام ويندوز (Windows Desktop App)

مرحباً بك! لقد تم تجهيز المشروع بالكامل وتكوينه بالاعتماد على تقنية **Electron** ومحزم التطبيقات **Electron Builder**، مما يتيح لك تشغيله وبناء ملف تنفيذي خارجي (`.exe`) خاص بنظام ويندوز ليعمل محلياً بالكامل على حاسوبك الشخصي وبأعلى كفاءة وسرعة.

---

## 🛠️ الخطوة 1: تصدير المشروع من منصة AI Studio
1. من الزاوية العلوية للمنصة (أو قائمة الإعدادات)، اختر **Export / تصدير**.
2. قم بتحميل كود البرنامج كملف مضغوط **ZIP** (أو قم بربطه وتصديره مباشرة إلى حساب **GitHub** الخاص بك ثم تحميله).
3. فك الضغط عن الملف في مجلد مستقل على جهاز الكمبيوتر الخاص بك.

---

## 💻 الخطوة 2: تهيئة البيئة المحلية وتثبيت الحزم
يجب أن يكون لديك برنامج **Node.js** مسبق التثبيت على جهازك (إذا لم يكن لديك، يمكنك تحميله مجاناً من الموقع الرسمي [nodejs.org](https://nodejs.org/)).

1. افتح نافذة الأوامر (Command Prompt أو PowerShell) في مجلد المشروع الذي قمت بفك ضغطه.
2. قم بتشغيل الأمر التالي لتثبيت جميع المكتبات والاعتماديات بما فيها محرك Electron لسطح المكتب:
   ```bash
   npm install
   ```

---

## 🚀 الخطوة 3: التشغيل والتطوير المحلي
يمكنك تجربة وتشغيل البرنامج مباشرة كشاشة تطبيق ويندوز محلي أثناء التطوير عبر تشغيل الأمرين التاليين معاً:

1. لتشغيل خادم التطوير السريع لـ React:
   ```bash
   npm run dev
   ```
2. لتشغيل نافذة تطبيق سطح المكتب (Electron) المرتبطة بالنسخة المحلية:
   ```bash
   npm run electron:dev
   ```

---

## 📦 الخطوة 4: بناء وتصدير ملف التثبيت المباشر للويندوز (`.exe`)
لبناء تطبيق ويندوز نهائي مغلق ومستقل، لا يحتاج لفتح أي متصفحات ويعمل بضغطة زر واحدة:

1. في نافذة الأوامر، اكتب الأمر التالي:
   ```bash
   npm run electron:build
   ```
2. سيقوم المحرك تلقائياً بتهيئة الأكواد وضغطها، ثم بناء التطبيق.
3. بمجرد الانتهاء، ستجد مجلداً جديداً ظهر في جهازك باسم: **`dist-desktop`** وبداخله:
   * **ملف التثبيت (Installer - لنظام ويندوز)**: يقوم بتثبيت البرنامج على جهازك وعمل اختصار على سطح المكتب.
   * **ملف النسخة المحمولة (Portable - لا يحتاج لتثبيت)**: ملف `.exe` يعمل مباشرة بمجرد الضغط عليه من أي فلاش أو مجلد ومناسب جداً للتشغيل السهل والسريع.

---

###  ملاحظات هامة جداً:
* **سرية العناوين والوضعية**: تدعم النسخة الحالية الانتقال السلس والممتاز بين **الوضع الفاتح (Light Theme)** و**الوضع الداكن (Dark Theme)** مع حل مشكلات تباين الخطوط والعناوين بنجاح تام.
* **العمل المستقل**: لا يحتاج الأرشيف أو النظام لاتصال إنترنت لتشغيله محلياً عند تهيئته إلا في حال رغبتك بالاتصال بخدمات سحابية خارجية مستقبلاً.
